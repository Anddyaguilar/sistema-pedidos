# sistema-pedidos
sistema inteligente para gestion de pedidos

usar npm install para instalr las paqueterias tanto en fronten y backend 
crear en el backend un archivo .env para la conexion a la bd

DB_HOST=localhost
DB_PORT=3306
DB_USER=root

DB_PASS=Conexion12345
DB_NAME=sistema_pedido

FRONTEND_URL=http://localhost:3000



# Entorno
NODE_ENV=development
DEBUG=true



version de node a  usar 22.12.0
version de npm a usar 11.6.3
